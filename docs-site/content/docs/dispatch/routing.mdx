---
title: 一条消息分到哪
description: 私聊里的一条消息进默认组、进某个任务组、当场回一句，还是不派出：只看第一个空白之前的那一段，和命令完全相同才算命令
---

白名单放进来的每一条私聊，都先去掉首尾空白、统一换行，然后过五道检查，前一道能下结论就不往下走。
「第一段」是第一个空白（半角空格、全角空格或换行）之前的那一段，它必须和某个命令**完全相同**才算命令：不做前缀匹配、不设别名。

选一条消息，看它走过哪几道、落在哪个结论上、机器人回什么。例子里假设主人私聊没绑定、用默认工作区；用 `qq-bot.group.add` 登记了 `/mmc`；有插件注册了直接命令 `/血糖`；`/论文` 同时被命令登记和插件注册：

结论分三种去向：进队列的派给 agent；当场回一句的（`/帮助`、`/状态`、`/新会话`、直接命令）不排队、不开会话；其余回一句原因、不派出。
以「/」开头的未知命令不当成任务派到默认组，是为了让拼错的命令当场报出来，代价是真想发以「/」开头的任务文本要换个写法，见[按命令分任务组](/trajectory/2026-10-08-slash-command-task-groups)。
分到任务以后一轮怎么走，见[派任务](/docs/dispatch)。
