**本页回答**：这个仓是什么、由哪几块组成、从哪一页接着读。

这个仓做一个 gwb 插件 `@godcreator/gwb-qq-bot`：常驻连 QQ 开放平台的 WebSocket 网关，收私聊与群 @ 消息，
把任务交给这个聊天绑定的执行端（ZCode 或 Claude Code），agent 做完调 `qq-bot.report`，结果发回原聊天。
一个机器人可以接多个群和私聊：每个聊天绑一个工作区和一个执行端，同一个聊天一次做一件、后面的排队；任务和结果始终属于发起它的聊天。

接入采用 QQ 官方机器人 API。平台侧通过服务范围和开发体验号码控制可用对象，插件侧通过 openid 白名单控制谁能派本机任务。
取舍的完整记录见轨迹区的根卡；派单这一组插件之间怎么接，整体的接缝图在接缝图集单元 uxje5-gwb-seams。

仓的组成：

- `plugins/qq-bot/`：插件包（唯一成员），分为 QQ 协议与连接、消息归一与回复选路、聊天表、一轮的生命周期、执行端适配层、插件入口。
  逐块的契约与钉码见[插件页](/docs/qq-bot)
- `docs-site/`：这个文档站。仓根 README / AGENTS / CLAUDE 与包里 SKILL.md 是生成物，正本在 `content/docs/outputs/`
- `probes/`：自包含实验材料；每个实验分别保存输入、运行方法与证据
