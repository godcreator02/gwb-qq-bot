**本页回答**：这个仓是什么、由哪几块组成、从哪一页接着读。

这个仓做一个 gwb 插件 `@godcreator/gwb-qq-bot`：常驻连 QQ 开放平台的 WebSocket 网关，
收私聊与群 @ 消息，把任务文本经命令总线派给运行中的 ZCode 桌面端执行，轮询结果后回推 QQ。
你在外面用手机发一句话，家里的电脑就让 ZCode 开始干活，干完把总结发回手机——这是它存在的全部目的。

接入采用 QQ 官方机器人 API。平台侧通过服务范围和开发体验号码控制可用对象，
插件侧通过 openid 白名单控制谁能派本机任务。新版后台使用当前正式 API，
不要把开发体验号码当成历史沙箱。取舍的完整记录见轨迹区的根卡。

仓的组成：

- `plugins/qq-bot/`：插件包（唯一成员），源码七个文件——协议层（`qq-protocol` / `qq-rest` / `qq-gateway`）、
  纯函数层（`routing` / `reply-window`）、桥接层（`bridge`）、入口（`index`）。逐块的契约与钉码见[插件页](/docs/qq-bot)
- `docs-site/`：这个文档站。仓根 README / AGENTS / CLAUDE 与包里 SKILL.md 是生成物，正本在 `content/docs/outputs/`
- `probes/`：实验材料（暂无）
