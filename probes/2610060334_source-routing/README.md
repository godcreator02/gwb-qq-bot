## 问什么

一个 QQ 机器人接收两个项目群和主人私聊时，能否隔离来源与会话，同时让同工作区任务排队，并在重载、改绑和旧数据迁移后保持原有边界？

## 怎么运行

在本目录执行第一行命令。只需要 Node.js 24 或更新版本，不需要安装依赖。`input/bridge.mjs` 是冻结后的 QQ bridge ESM bundle；`input/fixtures.json` 固定实验中的虚构 home、群、成员与项目。脚本只使用 Node 内置模块，不引用仓内源码或仓依赖树，不连接真实 QQ、ZCode 或 GWB home，不读取凭据。

实验用内存模拟持久化、GWB 命令与 QQ 发送。每项均通过公开入口送消息、收回报，再断言实际派单和回复行为。异步队列推进只在实验观察器中短暂等待，不向被测 bridge 增加轮询。每次运行把完整断言结果、派单来源元数据、模拟命令/回复和错误保存在独立的 `runs/*.json`；失败记录也保留。
