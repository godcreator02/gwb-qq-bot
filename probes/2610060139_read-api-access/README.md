## 问什么

当前 A、B 两个机器人对官方基础查询、QQ群成员/群管理查询、菜单/面板查询、频道发现接口实际具有什么访问能力？

## 怎么运行

在本目录运行第一行命令，Node.js 24，零第三方依赖。本目录的 `api.mjs` 和 `input/targets.json` 是固定实验输入，不引用仓内实现或其他实验。凭据只在运行时读取本机 `%APPDATA%/gwb-kernel/homes/<home>/credentials.json`；可用 `QQ_PROBE_HOMES_ROOT` 指定自己的 home 根目录。运行前校验 AppID 与目标一致；不得将凭据复制进实验目录。

脚本除获取访问凭证外只执行 GET，不改变接收范围、不关闭插件。记录每次 HTTP 状态、QQ 错误码和脱敏正文到新增 `runs/<运行时刻>.json`，不覆盖历史运行。只有 HTTP 成功才记 success；permission-denied 表示请求实到但账户无权限，不能当接口业务验证通过。频道后续查询只使用实际发现的频道 ID。
